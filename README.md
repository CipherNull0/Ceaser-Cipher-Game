# Caesar Cipher Game

## :book: About the Game

The Caesar Cipher Game is a fun, interactive game where players decode secret messages that have been encrypted using the Caesar Cipher. The goal is to figure out the original message by using the shift key and the alphabet as a guide.

This game helps players learn about basic encryption, decryption, and cybersecurity while improving their problem-solving skills.

## :video_game: How to Play

1. Open the game and click **Start Game**.
2. Look at the encrypted message displayed on the screen.
3. Check the shift key to see how many letters were moved during encryption.
4. Use the alphabet reference to help decode the message.
5. Type your decoded message into the answer box.
6. Click **Check Answer** to see if your answer is correct.
7. Earn points for correct answers and continue through all 10 rounds.
8. View your final score when you finish the game.

## :star: Features

- **Score System:** Earn 10 points for each correct answer.
- **10 Rounds:** Decode up to 10 secret messages in each game.
- **Alphabet Reference:** View all 26 letters of the alphabet.
- **Random Messages:** Each round selects a phrase and a shift key.
- **Answer Checking:** Receive feedback when your answer is correct or incorrect.
- **Empty Answer Protection:** The game asks you to enter a message if you submit an empty answer.
- **Hints:** Get help by learning how many letters to shift backward.
- **Final Score:** See your total score out of 100 points.
- **Play Again:** Restart the game and try to beat your previous score.
- **Pastel Design:** Enjoy a lavender and pink themed interface.

## :brain: What Is a Caesar Cipher?

A Caesar Cipher is a simple encryption method that shifts each letter of a message by a fixed number of positions in the alphabet.

For example, with a shift key of 3:

- A becomes D
- B becomes E
- C becomes F

To decrypt the message, the player shifts each letter backward by the same number of positions.

## :hammer_and_wrench: Technologies Used

- **HTML:** Creates the structure of the game.

## :rocket: How to Run the Game

1. Download or copy the game files.
2. Open the `index.html` file in a web browser, such as Google Chrome or Microsoft Edge.
3. Click **Start Game** and begin decoding!

No additional software or installation is required to play the standalone HTML version.
